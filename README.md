## Features

### Campaign Statistics with Charts

The application includes interactive charts for campaign performance visualization using MUI X Charts:

- **Bar and Line Charts**: Toggle between bar and line chart views
- **Multiple Metrics**: Display requests sent, connected, replied, and positive counts
- **Real-time Data**: Charts update based on selected profile filters
- **Summary Statistics**: Shows totals for all key metrics

The charts are implemented in `components/charts/CampaignChart.tsx` and integrated into the campaigns page (`app/dashboard/campaigns/page.tsx`).

### Dependencies

- **MUI X Charts**: For data visualization
- **Material UI**: Core UI components and theming
- **Emotion**: CSS-in-JS styling
